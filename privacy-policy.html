Chat Jump 개인정보 처리방침

시행일: 2026년 11월 19일 (v1.16.0 갱신) · 문의: chatjump.official@gmail.com

Chat Jump(이하 "확장 프로그램")는 claude.ai, chatgpt.com, gemini.google.com 사이드바에 미니 게임과 랭킹 기능을 제공하는 Chrome 확장 프로그램입니다. 이 문서는 확장 프로그램이 어떤 정보를 다루는지 설명합니다.

1. 수집·이용하는 정보

항목목적저장 위치
익명 ID (확장 프로그램이 무작위로 생성)랭킹에서 이용자 구분브라우저 로컬 저장소 + 랭킹 서버
닉네임 (자동 생성되며 이용자가 변경 가능)랭킹 표시브라우저 로컬 저장소 + 랭킹 서버
게임별 점수, 플레이 시간(초), 일일 도전 점수랭킹 집계 및 비정상 점수 차단랭킹 서버
하루 1회의 익명 사용 기록(익명 ID, 날짜)일간·월간 사용자 수 집계랭킹 서버
광고 노출·클릭 횟수(광고 ID, 날짜 단위 합계)광고 성과 집계 — 개인을 식별할 수 없음랭킹 서버
업적·누적 플레이 기록업적 표시브라우저 로컬 저장소(서버로 전송하지 않음)
설정값 (위젯 위치, 게임 속도, 표시할 게임, 언어, 답변 완료 알림, 소리 on/off)사용자 설정 유지브라우저 로컬 저장소

2. 수집하지 않는 정보

  • 대화 내용, 프롬프트, 답변, 업로드한 파일 등 claude.ai·chatgpt.com·gemini.google.com의 대화 데이터는 읽거나 저장하거나 전송하지 않습니다.
  • 이름, 이메일, 전화번호, 계정 정보, 결제 정보를 수집하지 않습니다.
  • 확장 프로그램은 위젯을 넣을 위치를 찾기 위해 사이드바의 메뉴 링크(예: "새 채팅")만 확인하며, 이 정보는 외부로 전송되지 않습니다.
  • "답변 완료 알림"을 위해 화면에 답변 중지 버튼이 보이는지만 브라우저 안에서 확인합니다. 답변 내용은 읽지 않으며, 이 확인 결과도 외부로 전송하지 않습니다. 설정에서 끌 수 있습니다.

3. 외부 서버 이용

랭킹 기능을 위해 Google Apps Script/Google 스프레드시트로 운영되는 서버(script.google.com)와 통신합니다. 전송되는 내용은 위 1항에 표시된 항목(익명 ID, 닉네임, 점수, 플레이 시간, 익명 사용 기록, 광고 집계)에 한정됩니다.

4. 광고

확장 프로그램에는 "AD"로 표시되는 스폰서 광고 영역이 있을 수 있습니다. 스폰서 카드는 클릭 시 광고주 페이지가 새 탭에서 열리며, 확장 프로그램은 광고 카드의 노출·클릭 횟수를 개인 식별 정보 없이 합계로만 집계합니다. 광고 목록은 운영자의 서버에서 불러옵니다. 광고주 페이지에서의 정보 처리는 해당 사이트의 방침을 따릅니다.

5. 보관 및 삭제

  • 브라우저에 저장된 정보는 확장 프로그램을 삭제하면 함께 삭제됩니다.
  • 랭킹 서버의 기록(익명 ID·닉네임·점수)의 삭제를 원하시면 위 문의처로 익명 ID와 함께 요청해 주세요.

6. 제3자 제공

수집한 정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다.

7. 방침 변경
